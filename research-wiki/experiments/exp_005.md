# Setup

- Dataset: CSL-Daily, only classes with ≥3 signers
- Split: 2 signers → train, 1 signer → test (strict cross-signer generalization)
- `max_classes = 1024`, `train_samples = 2048`, `val_samples = 209`, `test_samples = 1024`
- Classifier: temporal conv (not mean pooling — first version with mean pooling failed at full-class scale due to extreme few-shot setting)
- Input: frozen VAE continuous embeddings

## Results

| Metric | Value |
|--------|-------|
| train_acc | 1.0000 |
| val_acc | 0.5789 |
| test_acc | 0.6221 |
| test_top5_acc | 0.8174 |

## Verdict

**Strongly supports claim:C5** — VAE embeddings have significant cross-signer discriminability. Embedding quality is NOT the bottleneck for downstream failure. The problem is in how Qwen/mT5 processes these embeddings, not in the embeddings themselves.
