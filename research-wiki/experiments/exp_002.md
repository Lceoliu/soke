# Setup

Train Qwen2.5 on 1, 4, and 12 training samples for each of the three tasks (t2m, m2t, mc). Prior pipeline bugs caused earlier overfit to fail — these were fixed first:
1. Training and validation were using different token sources
2. pad / `lengths` handling was wrong
3. t2m training prompt ≠ inference prompt
4. Random token-drop augmentation was left on during overfit

## Results

After fixes: `overfit1 / overfit4 / overfit12` all succeed. All three tasks (m2t, t2m, mc) can be completely fit on small data.

## Verdict

**Supports claim:C3** — Qwen pipeline training/inference consistency is now correct.
