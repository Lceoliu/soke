# Setup

Full dataset training with Qwen2.5-0.5B and Qwen2.5-3B on combined t2m + m2t + mc tasks. LoRA rank=64, embed_tokens + lm_head fully trainable.

Configurations: `configs/soke_full_m2t_0_5b_pw00.yaml`, `configs/soke_full_m2t_0_5b_pw05.yaml`, `configs/soke_full_qwen2_5_8b_pw05.yaml`

## Results

- Train loss decreases normally
- Val loss / ppl increases (diverges from train)
- Test m2t: generated text is syntactically valid English but semantically unrelated to GT
- Model retains general text continuation ability — no catastrophic forgetting
- `m2t_prefix_loss_weight=0.5` improves val ppl significantly vs `pw=0.0` (44 epoch, 0.5B, m2t-only comparison)

## Verdict

**Invalidates idea:002** — decoder-only Qwen fails full-train generalization at current data scale.
**Supports claim:C2** — LM fine-tuning does not reliably convert sign embeddings into semantic translation.
`pw=0.5` is necessary but not sufficient (supports partial claim for prefix loss weight).
