# Setup

After mT5 full train, test whether the model actually uses motion embeddings: replace / randomly shuffle the motion embedding sequence while keeping text decoder unchanged. Measure BLEU4 change.

## Results

- Normal test: BLEU4 ≈ 2
- Motion shuffled / replaced: BLEU4 ≈ 0.2

10× drop confirms motion embeddings are being used.

## Verdict

**Supports claim:C4** — mT5 does use motion embeddings, it is not ignoring them. The full-train failure is not a "silent modality collapse".
